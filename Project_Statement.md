# Project Statement

## Project Title

**Mini Hospital / Patient Record System**

## Problem Statement

Managing patient information manually can become difficult even in a small clinic or hospital environment. Basic information such as patient identity, age, gender, assigned doctor, department, and consultation status needs to be organized so that it can be quickly accessed and updated.

The Mini Hospital / Patient Record System is designed to provide a simple digital solution for managing these basic patient records.

The application uses Python and Object-Oriented Programming concepts to create, search, display, update, and delete patient records through a command-line interface.

## Project Objective

The primary objective of this project is to develop a simple patient record management application that demonstrates how software can be used to organize basic hospital information.

### Specific Objectives

1. Create and store patient records.
2. Assign a unique Patient ID to each patient.
3. Search patient records using ID or name.
4. Display complete patient information.
5. Assign doctors and departments.
6. Update doctor and department assignments.
7. Track consultation status.
8. Delete patient records when required.
9. Prevent duplicate Patient IDs.
10. Demonstrate Object-Oriented Programming in Python.

## Functional Requirements

The system shall provide the following functions:

### Patient Registration

The system shall allow users to enter:

* Patient ID
* Name
* Age
* Gender
* Doctor
* Department
* Consultation Status

### Patient Search

The system shall allow searching by:

* Patient ID
* Patient Name

### Patient Display

The system shall display:

* Individual patient records
* All patient records

### Doctor and Department Management

The system shall allow the assigned doctor and department to be updated.

### Consultation Management

The system shall allow consultation status to be changed between:

* Scheduled
* In Progress
* Completed
* Cancelled

Custom status values are also supported.

### Patient Deletion

The system shall allow an existing patient record to be deleted using the Patient ID.

## Non-Functional Requirements

The application should:

* Be simple to operate.
* Provide clear console messages.
* Prevent duplicate patient IDs.
* Continue operating until the user selects Exit.
* Use modular and object-oriented code.
* Provide understandable output.

## Target Users

The prototype can be used for learning and demonstration by:

* Students
* Python beginners
* OOP learners
* Software development trainees
* Academic project evaluators

## Scope

The current system focuses only on basic patient record management.

It does not include:

* Medical diagnosis
* Prescription management
* Billing
* Insurance
* Laboratory management
* Authentication
* Persistent database storage
* Real-time hospital integration

## Expected Outcome

The expected outcome is a functional Python console application capable of performing basic patient record CRUD operations.

The project also establishes a foundation for future development into a database-driven, web-based hospital management system.

## Success Criteria

The project can be considered functionally successful when the application can:

* Add a patient successfully.
* Reject duplicate Patient IDs.
* Search for an existing patient.
* Display patient records.
* Update doctor and department information.
* Update consultation status.
* Delete patient records.
* Handle invalid menu selections without terminating unexpectedly.
* Exit correctly when requested.

## Future Scope

The system can be expanded into a complete hospital management platform by adding:

* Database integration
* Authentication
* Role-based access control
* Doctor management
* Appointment scheduling
* Medical history
* Prescription management
* Billing
* Laboratory management
* Web frontend
* REST APIs
* Reporting and analytics
* Audit logging
* Backup and recovery

## Conclusion

The Mini Hospital / Patient Record System provides a simple and practical demonstration of Python programming and Object-Oriented Design. It solves the basic problem of organizing patient records while providing a foundation for developing a more advanced hospital management platform.
